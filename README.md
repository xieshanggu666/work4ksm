# 回测工坊：个人投资回测与风险分析平台

一个可本地运行的个人投资策略回测与风险分析平台。内置模拟行情引擎、技术指标库、回测撮合器、风险指标与蒙特卡洛模拟，提供 Web 交互界面。

## 快速开始

```bash
npm install
npm run dev
```

启动后自动打开浏览器（自动选择空闲端口）。`npm test` 运行测试套件。

## 架构

```
invest_backtest/
├── engine/
│   ├── market.js       模拟行情生成（GBM + 波动率状态切换 + 前复权）
│   ├── indicators.js   技术指标（SMA/EMA/RSI/MACD/布林带/ATR）
│   ├── backtest.js     回测撮合器（信号延迟一日、固定/ATR 动态止损止盈、成本模型）
│   ├── metrics.js      风险指标（年化/夏普/索提诺/最大回撤/卡玛）
│   └── montecarlo.js   自助法蒙特卡洛模拟
├── server.js           HTTP 服务（静态托管 + 回测 API）
├── web/                Vue3 + Canvas 前端
└── tests/              引擎测试套件
```

## 核心语义

- **信号延迟**：策略在第 `i` 根 K 线收盘后产生信号，于第 `i+1` 根开盘成交，杜绝前视偏差。
- **止损止盈**：两种模式共用同一套撮合语义——持仓期间按当日最高/最低价触发；若开盘跳空越过触发价，按开盘价成交；止损平仓当日不再进场。触发价只使用前一交易日及之前的数据，无未来函数。
  - `stopMode: "fixed"`（默认）：`stopLoss`/`takeProfit` 为相对入场价的固定比例，行为与旧版本完全一致，旧参数可复现原结果。
  - `stopMode: "atr"`：止损为吊灯式跟踪止损 `持仓内最高价 - atrStopMult × 波动缩放 × ATR(atrN)`（只上不下）；止盈为 `入场价 + atrTakeMult × 波动缩放 × ATR`，随波动状态浮动；倍数为 0 表示不启用。`volState` 开启时，按 `clamp(ATR / 前 volLookback 根 ATR 均值, 0.5, 2)` 缩放——高波动加宽、低波动收紧。ATR 预热期内不启用动态止损止盈。
- **交易明细**：逐笔交易在原有字段基础上记录 `stop_mode`、`stop_price`、`take_price`（出场 bar 实际生效的触发价），ATR 模式另附 `atr` 与 `vol_scale`，与撮合使用同一套数值。
- **成本模型**：成交价叠加滑点（买入上浮、卖出下浮），双边收取手续费。
- **风险指标**：收益序列采用对数收益，年化按 252 个交易日折算；下行波动只统计负收益；最大回撤记录回撤区间。
- **蒙特卡洛**：对历史对数收益自助重采样生成模拟路径，输出 5%/50%/95% 分位带与亏损概率。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 系统信息 |
| POST | `/api/market` | 生成模拟行情 |
| POST | `/api/backtest` | 行情 + 策略 + 交易参数，返回权益曲线/回撤/逐笔交易/风险指标 |
| POST | `/api/montecarlo` | 对权益曲线做蒙特卡洛模拟 |

## 测试

`npm test` 覆盖指标手算、撮合时点、固定/ATR 止损语义、波动状态缩放、成本模型、最大回撤、蒙特卡洛统计性质、旧参数复现等 30 个用例。
